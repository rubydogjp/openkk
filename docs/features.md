# オープン会計 — 機能カタログ

個人事業主向け複式簿記ライブラリ「オープン会計」が提供する機能の全体像。

---

## 1. 会計期間管理 (Fiscal Period Management)

| 機能           | 説明                                                                                                                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 期間の作成     | 任意の開始日・終了日で会計期間を作成                                                                                                                                                                                           |
| 期間の選択     | 複数期間を持ちつつ対象期間を切り替え                                                                                                                                                                                           |
| 期間の削除     | 開始前 (`pre_opening`) の期間だけ、期間を開始の手順から削除できる (`fiscalPeriods.remove`)                                                                                                                                     |
| 期間フェーズ   | `pre_opening` → `journalizing` → `pre_closing` → `post_closing`                                                                                                                                                                |
| バックアップ   | 会計期間のデータを、そのまま帳簿のファイル (`<期間名>.openkk`) として書き出す。どの製品でも「次の期間へ」の手順から出せる (下の「バックアップ」)。期間の状態は変えない                                                         |
| ロック判定     | `buildPeriodLockMessage` でステージ別の編集可否を判定                                                                                                                                                                          |
| 以前の圧縮保存 | 圧縮保存の操作はなくした。以前に圧縮保存した期間は、データが残っていればふつうの本締め済みの期間として見られる。データを削除済み (`purged`) の期間は知らせだけを出し、保存してあるファイルを取り込むと新しい期間として見られる |

## 2. 仕訳入力 (Journal Entry Management)

| 機能               | 説明                                                   |
| ------------------ | ------------------------------------------------------ |
| 仕訳の作成         | 借方・貸方・金額・摘要・取引先・税区分・事業区分を入力 |
| 複合仕訳           | 1 仕訳に複数の借方/貸方明細行 (`lines[]`) を持てる     |
| 月次ナビゲーション | 月単位でページネーションして表示                       |
| 仕訳の編集         | 行クリックでドロワーを開き各フィールドを変更           |
| 仕訳の削除         | ドロワー内の削除ボタン → 確認ダイアログで実行          |
| 事業按分率         | 0–100%（小数可）で指定し、期末に個人負担分を振替       |
| 簡単入力ガイド     | テンプレートから借方・貸方科目を自動補完するウィザード |

## 3. ファイルインポート / エクスポート (Data Portability)

仕訳タブの「表」で、会計期間の仕訳を 1 枚の表で見る。書き出し・取り込みはこの画面で行う。

| 機能                  | 形式           | 説明                                                                                                                                                                                   |
| --------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 表の形                | CSV (`.csv`)   | 1 行 = 借方・貸方の 1 組。列は 仕訳番号・日付・借方科目・借方金額・貸方科目・貸方金額・摘要・取引先・税区分・事業区分・事業割合。複合仕訳は同じ仕訳番号の行が続く (`journal-table.ts`) |
| エクスポート          | CSV            | 期間内の仕訳 (自動の行を除く) を表の形で書き出す。金額は数字だけ、事業割合は `80` のように書く                                                                                         |
| インポート (置き換え) | CSV            | 仕訳番号で今の仕訳と突き合わせ、追加・変更・削除を表で見せてから反映する。仕訳番号が空の行は新しい仕訳、ファイルにない仕訳は消す。読めない行があれば行番号つきで知らせ、何も変えない   |
| 科目の書き方          | CSV            | 科目名で書く。名前が重なる科目は `消耗品費（売上原価）`・`貸倒引当金（固定資産）` のように区分を付ける (`buildBookAccountLabels`)                                                      |
| JSON (非推奨)         | JSON (`.json`) | 互換のために残す。`schema: "openkk-journal-v1"` 形式で書き出し、取り込みは `localId` が既存仕訳と重複しないものだけ足す。`事業主借` は種別が `liability` でも純資産として取り込む      |
| 以前の形式の CSV      | CSV (`.csv`)   | `localId` 列のある以前の CSV は読むだけ残す (`importEntriesFromLegacyCsv`)。書き出した時点の控えなので置き換えにせず、JSON と同じく足すだけで取り込む                                  |

## 4. 固定資産管理 (Fixed Asset Management)

| 機能                   | 説明                                                                                                                              |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 固定資産の登録         | 名称・取得日・取得価額・耐用年数・事業按分率を入力                                                                                |
| 固定資産の編集         | 記帳中に各フィールドを更新                                                                                                        |
| ステータス管理         | `active` / `sold` (売却済) / `disposed` (廃棄済) / `retired` (完了)。完了年度の償却費は計上し、翌期へは繰り越さない               |
| 減価償却バーチャル仕訳 | 当期償却費（期首〜期末／処分日の**月割**, 取得月算入の暦月ベース, 備忘価額1円で打ち切り）を自動生成 (`computePeriodDepreciation`) |
| 売却バーチャル行       | 売却済資産の処分日に「期首〜処分日の当期償却費」＋売却仕訳（処分日簿価で資産を除き、差額を固定資産売却損益）を自動生成            |
| 廃棄バーチャル行       | 廃棄済資産の処分日に「期首〜処分日の当期償却費」＋残存簿価を固定資産除却損として除却                                              |
| 家事按分               | 減価償却費・除却損は全額計上し、`businessRate` の個人負担分は本締め時の按分振替仕訳でまとめて事業主貸へ振替                       |

## 5. 期首繰越 / 再振替 (Opening Carryover)

| 機能                   | 説明                                                                                                                                                                                                                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 再振替仕訳の登録       | 翌期作成時に未払・前払などの候補から対象を選択。期首仕訳は後から編集可能                                                                                                                                                                                                                     |
| バーチャル行として表示 | 期首の月の仕訳一覧に「再振替」バッジ付きで自動表示                                                                                                                                                                                                                                           |
| 期首残高の入力         | 資産・負債の期首残高 (`opening.balanceLines`) を貸借一致で入力                                                                                                                                                                                                                               |
| 引き継ぎの上書き       | 開始後の期間でも、期首のBSの手順から引き継ぎ元を選び、期首のBS・再振替・固定資産を選んだものだけ置き換える (`fiscalPeriods.applyCarryover`)。仮締めまで何度でもやり直せる                                                                                                                    |
| 別の帳簿からの引き継ぎ | 別の帳簿にある期間 (本締めと書類の受け取りを終えたもの) を圧縮保存と同じ形で渡し、期首のBS・再振替・固定資産を引き継ぐ (`fiscalPeriods.applyCarryoverFromArchive`)。再振替は渡した仕訳の並び順で選ぶ。openkk-cli の `opening carry` と、会計期間ごとに帳簿を分ける `books-db-adapter` が使う |

## 6. 締め処理フロー (Closing Flow)

ステップ UI が期間の状態に合わせて次のステップへ誘導する。`deriveSteps` は 6 ステップ構成で、仮締め (pre closing) は独立ステップではなく「日々の仕訳」ステップの完了操作として扱う。

| ステップ          | 内容                                                                                           |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| 1. 期間を開始     | 期間設定の確認 (開始日・終了日)                                                                |
| 2. 期首のBSを入力 | 貸借対照表の期首残高を入力                                                                     |
| 3. 日々の仕訳     | 仕訳の入力・インポート・進捗グラフの確認。完了時に `runPreClosing` で仮締めし仮の帳票3点を生成 |
| 4. 本締め         | 最終帳票3点を生成・財務諸表サマリーを表示。本締め後は変更不可                                  |
| 5. 書類を受け取る | 生成済み帳票を確認し受取完了                                                                   |
| 6. 次の期間へ     | BS 繰越・再振替・固定資産データの引き継ぎを確認。バックアップのダウンロードもここで行う        |

仮締め (`runPreClosing`) は `journalizing → pre_closing`、本締め (`runFinal`) は `pre_closing → post_closing` に遷移させる。本締め前なら `cancelPreClosing` で記帳に戻れる。

減価償却・再振替・家事按分の自動仕訳を仮帳票に含め、本締め時に保存する。サーバーが保存済みデータから再計算して検証するため、仮帳票と確定帳票の数字は一致する。

## 7. 財務帳票 (Financial Reports)

| 帳票                            | 説明                                                       |
| ------------------------------- | ---------------------------------------------------------- |
| 仕訳帳 (Journal)                | 全仕訳を日付順に印刷用 HTML として生成                     |
| 総勘定元帳 (General Ledger)     | 科目ごとの残高推移を印刷用 HTML として生成                 |
| 財務諸表 (Financial Statements) | 損益計算書 (PL) + 貸借対照表 (BS) を印刷用 HTML として生成 |

生成した HTML は `PrintPort.openPrint(html)` 経由でブラウザの印刷ダイアログに渡す。帳票内のすべてのユーザーデータは HTMLエスケープ済み (`escapeHtml`)。

## 9. ストレージ (Storage)

| アダプタ            | 用途                                                     | 永続化                                           |
| ------------------- | -------------------------------------------------------- | ------------------------------------------------ |
| `legacy-db-adapter` | 26.3 までの SQLite OPFS (ブラウザ内の 1 つの DB)         | 前の版のデータ。移すときに読むだけ               |
| `memory-db-adapter` | インメモリ (揮発)                                        | ページリロードでリセット                         |
| `book-db-adapter`   | 帳簿 1 冊 (`.openkk`、SQLite) をブラウザのメモリ上に開く | 開いた側が書き出して保存する                     |
| `books-db-adapter`  | 会計期間ごとの帳簿に振り分ける (無印版)                  | 変わった帳簿を置き場 (ブラウザの中) へ自動で保存 |
| `disk-db-adapter`   | `.openkk` ファイル (SQLite) を Node で開く               | ファイルそのもの (openkk-cli)                    |

どれも `OpenkkDbPort` を実装しており差し替え可能。`.openkk` は中身が同じ SQLite なので、無印版が「保存」で書き出したファイルを openkk-cli で扱い、また無印版に取り込める。SQL・マイグレーション・最後に変えた時刻の記録は `sqlite-db-adapter` で共有する。無印版は 26.3 まで `legacy-db-adapter` の 1 つの DB にすべての期間を置いていた。今は期間ごとの帳簿に分けて置き、`legacy-db-adapter` は前の版の DB を移すときに読むだけ。

## 10. デフォルトマスターデータ (Built-in Master Data)

オープン会計 は個人事業主の青色申告を想定したデフォルト勘定科目・税区分・事業区分を内蔵する。

| データ   | 定数                          | 内容                                                                |
| -------- | ----------------------------- | ------------------------------------------------------------------- |
| 勘定科目 | `DEFAULT_BOOK_ACCOUNTS`       | 資産・負債・純資産・収益・費用の主要科目 219 件（専従者給与を含む） |
| 税区分   | `DEFAULT_TAX_CATEGORIES`      | 課税 10% / 軽減税率 8% / 免税 / 非課税 / 対象外（5件）              |
| 事業区分 | `DEFAULT_BUSINESS_CATEGORIES` | 第1〜第6種・対象外 (みなし仕入率区分、7件)                          |

勘定科目は既定IDのみ、税区分・事業区分は既定IDと利用者定義値を受け付ける。

## バンドル一覧

版は実行時切替ではなく **バンドル（別パッケージのアプリ）** で分ける。`bundle`（版）と `brand`（サイト URL・アカウントアイコン）は独立した概念。

| bundle     | パッケージ                                                       | 表示名 (`bundleLabel`) | DB                            | シードデータ               | 認証     |
| ---------- | ---------------------------------------------------------------- | ---------------------- | ----------------------------- | -------------------------- | -------- |
| `sim`      | `@rubydogjp/openkk-bundle-sim` (`packages/bundle-sim`)           | Sim版                  | memory + 固定時計             | なし (任意に作成)          | embedded |
| `demo`     | `@rubydogjp/openkk-bundle-demo` (`packages/bundle-demo`)         | デモ版                 | memory + 固定時計             | あり (buildOpenkkDemoSeed) | embedded |
| `original` | `@rubydogjp/openkk-bundle-original` (`packages/bundle-original`) | 無印版                 | 期間ごとの帳簿 (ブラウザの中) | なし                       | embedded |

無印版は、データをブラウザの中に置く。置き方は環境で変えない。ブラウザによっては、しばらく (Safari では 7 日ほど) 開かないとデータを消すことがあるので、重ねて出す知らせ「データはこのブラウザの中だけにあります」で伝え (閉じるまで、開くたびに出す)、利用者が自分でファイルに保存する。左上 (ほかの版で「オープン会計」と版の名前が出る場所) に「保存」ボタンを置き、今の会計期間の帳簿を `<期間名>.openkk` として書き出す (スマホは共有シート、それ以外はダウンロード)。ボタンの下に「保存していない変更があります」か「前回 11/3」を出し、変更があって 30 日保存していなければ、重ねて出す知らせで伝える (`OpenkkBookFilesPort`)。

保存したファイルは、期間の選択の「ファイル」→「ファイルを取り込む」で取り込む。取り込みは復元で、今のデータと混ぜない。まだない期間は足し、同じ期間は「ファイルで上書きしますか？」と確かめてから、ファイルを優先して上書きする (選べるのは「キャンセル」と「上書きする」)。今のデータと同じなら「今のデータと同じです。」と出して何もしない。アプリの側に保存していない変更があれば、それが失われることを知らせる。別に作られた同じ日付の期間は、今の帳簿が失われることを知らせる。日付が重なるだけの期間は取り込まない。同じブラウザでは 1 つのタブでだけ動き、2 つ目のタブは 1 つ目を閉じるまで待つ。前の版 (26.3 まで) のデータは、新しい版を初めて開いたときに期間ごとの帳簿に分けて移す (前のデータは消さない)。

どの製品にも圧縮保存の操作はない。「次の期間へ」の手順に、その会計期間のデータをそのままファイル (`.openkk`) として出す「バックアップをダウンロード」を置く (期間の状態は変えない)。無印版では、左上の「保存」と同じファイルになる。Sim版・デモ版など、データを帳簿のファイルとして持たない製品では、バックエンドから読んだ記録で帳簿のファイルを組み立てる (`records-book-files-adapter`)。期間の ID はそのまま保つ。

保存したファイルは、どの製品でも期間の選択の「ファイル」→「ファイルを取り込む」から取り込める。データを帳簿のファイルとして持たない製品では、新しい期間として足すだけで、日付の重なる期間があれば取り込まない (置き換えない)。前の版で作った圧縮済みファイル (zip) も、同じ入口から取り込める (中身が zip なら圧縮済みファイルとして読み、新しい期間として足す。日付の重なる期間があれば断る)。

製品は `bundle-<名前>` という箱で、動く形 (`client-browser`) と口の実装と設定を選んで束ねる。ブラウザで動かす配線は `@rubydogjp/openkk-client-browser`（`packages/client-browser`）に集約。

## 知らせ (Notices)

知らせは、画面の物を動かさないように前面へ重ねて出す (`OpenkkShellLayout` の中の下の中央。仕訳や固定資産を編集する画面が開いている間は、その左の空きか、下のボタンの上)。画面の流れの中には差し込まない。

| 種類                   | 見た目       | 閉じ方                                                                         | 例                                                                 |
| ---------------------- | ------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| うまくいった結果       | 緑のチェック | 5 秒で消える。× でも閉じる                                                     | 取り込みました・反映しました・書き出しました                       |
| 確かめてほしいこと     | 黄色の三角   | × で閉じる (閉じたものは、次に開いたときにまた出す)。直るまで出すものは × なし | 30 日ファイルに保存していない・読めない帳簿がある                  |
| うまくいかなかったこと | 赤のバツ     | 結果は × で閉じる。直るまで出すものは × なし                                   | 取り込めませんでした・ブラウザに保存できない・データを読み込めない |

同時に出すのは 3 枚までで、新しいものを下に足す。直るまで出すものを優先して残す。画面から出すときは `useOpenkkNotices().show()` (結果) か `useOpenkkStandingNotice()` (状態に合わせて出し入れ) を使う。CSV の違いの確認と入力欄のそばのエラーは、操作の途中に出るものなので、ここには入れない。

## 認証・ユーザー (Authentication)

`OpenkkUser = EmbeddedUser | CustomUser` を `OpenkkConfig.authMode` で切り替える。詳細は [`authentication.md`](./authentication.md) を参照。
